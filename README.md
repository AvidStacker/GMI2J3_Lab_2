# Software Testing Labs

This repository contains exercises and solutions focused on **unit testing** and **code coverage** in C#.  

## Contents

- **MSBankAccountTestSolution** – Bank account implementation with test coverage  
- **nUnitBankAccountTests** – Unit tests written with NUnit  
- **xUnitBankAccountTests** – Unit tests written with xUnit  
- **RomanNumerals** – Implementation of Roman numeral conversion  
- **RomanNumeralsTests** – Unit tests for Roman numeral logic  

## Additional Material

- Coverage reports included for test projects  
- Focus on comparing different unit testing frameworks (NUnit vs xUnit)  

---

### Tools & Environment

- **C# .NET** (Visual Studio solutions)  
- **NUnit** and **xUnit** for unit testing  
- Coverage reporting integrated
